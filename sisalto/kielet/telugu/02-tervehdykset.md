| Suomeksi | Telugu | ISO 15919 |
| --- | --- | --- |
| Terve / tervehdys | నమస్కారం | namaskāraṁ |
| Hyvää huomenta | శుభోదయం | śubhōdayaṁ |
| Hyvää iltaa | శుభ సాయంత్రం | śubha sāyantraṁ |
| Hyvää yötä | శుభ రాత్రి | śubha rātri |
| Näkemiin | వీడ్కోలు | vīḍkōlu |
| Kiitos | ధన్యవాదాలు | dhanyavādālu |
| Ei kestä / eipä mitään (vastaus kiitokseen) | పర్వాలేదు | parvālēdu |
| Ole hyvä (kohteliaasti pyydettäessä) | దయచేసి | dayacēsi |
| Tervetuloa | స్వాగతం | svāgataṁ |
| Kyllä | అవును | avunu |
| Ei | కాదు | kādu |
| Anteeksi | క్షమించండి | kṣamiṁcaṁḍi |
| (vastaus "mitä kuuluu": hyvin) | (నేను) బాగున్నాను | (nēnu) bāgunnānu |

Nimen jälkeen liitettävä pääte **-గారు (-gāru)** ilmaisee kunnioitusta
(esim. "Rāma gāru") — se ei koskaan liity suoraan pronominiin, vain
nimeen, titteliin tai sukulaisuussanaan, eikä sitä käytetä itsestä
puhuttaessa.

Huomaa ero kahden kohteliaan sanan välillä: **దయచేసి/dayacēsi**
tarkoittaa "olkaa hyvä" pyynnön yhteydessä (esim. jotain tarjottaessa
tai pyydettäessä), kun taas **పర్వాలేదు/parvālēdu** on se, mitä
sanotaan *vastaukseksi* kiitokseen — suunnilleen "ei kestä" tai "eipä
mitään". Parvālēdu kelpaa myös vastaukseksi anteeksipyyntöön ("ei se
mitään").

## Lukukappale

Seuraava lyhyt dialogi käyttää vain tämän luvun sanastoa: Rāma
tervehtii Lakṣmiä, ja Lakṣmi toivottaa hänet tervetulleeksi. Rāma
kiittää, ja lopuksi molemmat hyvästelevät.

| Puhuja | Telugu | ISO 15919 | Suomeksi |
| --- | --- | --- | --- |
| Rāma | నమస్కారం, లక్ష్మి గారు! | Namaskāraṁ, Lakṣmi gāru! | Terve, Lakṣmi! |
| Lakṣmi | నమస్కారం, రామ గారు! స్వాగతం! | Namaskāraṁ, Rāma gāru! Svāgataṁ! | Terve, Rāma! Tervetuloa! |
| Rāma | ధన్యవాదాలు! | Dhanyavādālu! | Kiitos! |
| Lakṣmi | పర్వాలేదు! | Parvālēdu! | Ei kestä! |
| Rāma | వీడ్కోలు, లక్ష్మి గారు! | Vīḍkōlu, Lakṣmi gāru! | Näkemiin, Lakṣmi! |
| Lakṣmi | వీడ్కోలు! | Vīḍkōlu! | Näkemiin! |
