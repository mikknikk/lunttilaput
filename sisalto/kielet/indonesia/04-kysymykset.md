| Suomeksi | Indonesia |
| --- | --- |
| mitä | apa |

| missä | di mana |

## Kyllä/ei-kysymykset

Kyllä/ei-kysymyksen voi muodostaa yksinkertaisesti nostamalla äänenpainoa
lauseen lopussa, aivan kuten suomessakin arkikielessä usein tehdään:

```
Kamu lapar?  (Oletko nälkäinen? — kirjaimellisesti "sinä nälkäinen?")
```

Muodollisemmassa kielessä lauseen alkuun lisätään sana **apakah**, joka ei
tarkoita mitään erikseen suomeksi käännettynä vaan ainoastaan merkitsee
lauseen kysymykseksi (samaan tapaan kuin espanjan kääntynyt kysymysmerkki
¿, mutta sanana lauseen alussa):

```
Apakah kamu lapar?  (Oletko nälkäinen? — muodollisempi)
```

## Wh-kysymykset

Kysymyssana sijoitetaan yleensä lauseen alkuun, kuten suomessakin:

| Indonesia | Suomeksi |
| --- | --- |
| Apa ini? | Mikä tämä on? |
| Siapa nama kamu? | Mikä sinun nimesi on? |
| Di mana kamu tinggal? | Missä sinä asut? |
| Kapan kamu datang? | Milloin sinä tulet? |
| Mengapa kamu terlambat? | Miksi olet myöhässä? |
| Bagaimana caranya ke sana? | Miten sinne pääsee? |
| Berapa harganya? | Paljonko se maksaa? |

## Vastausesimerkkejä

```
A: Apa kabar?               (Mitä kuuluu? — kirjaimellisesti "mitä uutta")
B: Baik-baik saja, terima kasih. Bagaimana dengan kamu?
   (Hyvää, kiitos. Entä sinulle?)
```

## Kertaus: sanajärjestys pysyy samana kysymyksessä

Toisin kuin englannissa, jossa kysymys usein vaatii apuverbin siirtämisen
lauseen alkuun (esim. "Do you...?"), indonesiassa perussanajärjestys
säilyy — vain kysymyssana tai -sävy lisätään. Tämä tekee kysymysten
muodostamisesta suhteellisen suoraviivaista tässä vaiheessa opintoja.
