---
title: 6. Verbit, aika ja kielioppi
---

## Ei verbitaivutusta

Indonesian verbit eivät taivu persoonan, luvun eivätkä ajan mukaan — sama
perusmuoto käy kaikkeen:

```
Saya makan.    (Minä syön.)
Kamu makan.    (Sinä syöt.)
Mereka makan.  (He syövät.)
```

Tämä on yksi suurimmista helpotuksista suomen tai englannin puhujalle
verrattuna esim. espanjaan tai jopa englannin kolmanteen persoonaan
("she eat**s**").

## Aikamuoto ilmaistaan sanoilla, ei taivutuksella

Koska verbi itse ei kerro aikaa, aikamuoto ilmaistaan erillisillä
apusanoilla ennen verbiä (tai jätetään kokonaan pois, jos asiayhteydestä
käy jo ilmi):

| Sana | Merkitys | Esimerkki |
| --- | --- | --- |
| sudah | jo (tehty/mennyt) | Saya sudah makan. (Olen jo syönyt.) |
| belum | ei vielä | Saya belum makan. (En ole vielä syönyt.) |
| sedang | parhaillaan (kesken) | Saya sedang makan. (Syön parhaillaan.) |
| akan | tulevaisuudessa | Saya akan makan. (Tulen syömään.) |
| mau | aikomus / halu | Saya mau makan. (Aion/haluan syödä.) |
| pernah | joskus (kokemus) | Saya pernah makan durian. (Olen joskus syönyt duriania.) |

## Kieltosanat kertauksena

- **tidak** — kieltää verbin tai adjektiivin: "Saya tidak makan" (en
  syö), "Ini tidak besar" (tämä ei ole iso).
- **bukan** — kieltää substantiivin: "Ini bukan makanan saya" (tämä ei ole
  minun ruokani).
- **belum** — "ei vielä", oma kieltosanansa aikaa varten (ks. yllä).

## Etuliitteet (imbuhan) — yleiskatsaus

Indonesia on agglutinoiva kieli: perussanaan liitetään etu- ja
jälkiliitteitä, jotka muuttavat merkitystä tai sanaluokkaa. Muutama
yleisin aloittelijalle:

| Etuliite | Vaikutus | Esimerkki |
| --- | --- | --- |
| me- | muodostaa aktiivisen verbin (usein äänteenmuutoksia) | pukul (isku) → memukul (lyödä) |
| ber- | muodostaa tekemistä/tilaa ilmaisevan verbin | main (leikki) → bermain (leikkiä) |
| di- | passiivin merkki | makan (syödä) → dimakan (tulla syödyksi) |
| ter- | tahaton teko tai superlatiivi | jatuh (pudota) → terjatuh (pudota vahingossa); besar (iso) → terbesar (suurin) |

`me-`-etuliite aiheuttaa usein äänteenmuutoksia sanan alussa (esim. `p`
katoaa: pukul → memukul, ei "mempukul") — tämä on oma laaja aihepiirinsä,
johon kannattaa syventyä vasta perussanaston ja -lauserakenteiden
opettelun jälkeen.

## Kertaava esimerkkilause

```
Saya sudah membeli buku itu, tapi saya belum membaca-nya.
(Olen jo ostanut sen kirjan, mutta en ole vielä lukenut sitä.)
```
(*membeli* = ostaa, me- + beli; *membaca* = lukea, me- + baca; *tapi* =
mutta; *-nya* = sitä/sen, viittaa kirjaan)
