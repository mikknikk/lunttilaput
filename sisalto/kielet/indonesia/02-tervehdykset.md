## Vuorokaudenajan mukaiset tervehdykset

| Suomeksi | Indonesia |
| --- | --- |
| Hei (yleinen, epämuodollinen) | Halo |
| Hyvää huomenta | Selamat pagi |
| Hyvää päivää (n. klo 11–15) | Selamat siang |
| Hyvää iltapäivää (n. klo 15–18) | Selamat sore |
| Hyvää iltaa/yötä | Selamat malam |
| Näkemiin (puhuja lähtee) | Selamat tinggal |
| Näkemiin (puhuja jää, toinen lähtee) | Selamat jalan |

Sana **selamat** tarkoittaa suunnilleen "onnea/tervehdys" ja edeltää
useimpia kohteliaita ilmauksia — sitä käytetään paljon laajemmin kuin
pelkissä vuorokaudenaikatervehdyksissä (esim. "Selamat makan" = hyvää
ruokahalua, "Selamat ulang tahun" = hyvää syntymäpäivää).

## Esittäytyminen

| Suomeksi | Indonesia |
| --- | --- |
| Nimeni on ... | Nama saya ... |
| Mikä sinun nimesi on? | Siapa nama kamu? / Siapa nama Anda? (kohtelias) |
| Olen suomalainen | Saya orang Finlandia |
| Mistä olet kotoisin? | Kamu berasal dari mana? |
| Olen kotoisin Suomesta | Saya berasal dari Finlandia |
| Hauska tutustua | Senang berkenalan dengan kamu |

## Kohteliaisuusfraasit

| Suomeksi | Indonesia |
| --- | --- |
| Kiitos | Terima kasih |
| Ole hyvä (vastaus kiitokseen) | Sama-sama |
| Anteeksi (huomion pyytäminen) | Permisi |
| Anteeksi (pahoittelu) | Maaf |
| Kyllä | Ya |
| Ei (verbit/adjektiivit) | Tidak |
| Ei (substantiivit) | Bukan |

Huomaa kaksi eri kieltosanaa: **tidak** kieltää verbin tai adjektiivin
("saya tidak tahu" = en tiedä), **bukan** kieltää substantiivin ("ini
bukan buku saya" = tämä ei ole minun kirjani). Palaamme tähän tarkemmin
luvussa 6.

## Pieni harjoitusdialogi

```
A: Halo! Nama saya Liisa. Siapa nama kamu?
B: Nama saya Budi. Senang berkenalan dengan kamu.
A: Senang berkenalan juga. Kamu berasal dari mana?
B: Saya berasal dari Jakarta. Kamu?
A: Saya berasal dari Finlandia.
```
(*juga* = myös)
