## Jokapäiväisiä hyödyllisiä fraaseja

| Suomeksi | Indonesia |
| --- | --- |
| En ymmärrä | Saya tidak mengerti |
| Voitko toistaa? | Bisa kamu ulangi? |
| Puhutko englantia? | Kamu bisa bahasa Inggris? |
| Ole hyvä (pyydettäessä apua) | Tolong |
| Ole hyvä (tarjottaessa/kutsuttaessa) | Silakan |
| Missä on vessa? | Di mana toilet/kamar kecil? |
| Auttaisitko minua? | Bisa kamu bantu saya? |
| Kuinka paljon tämä maksaa? | Berapa harga ini? |
| Liian kallis | Terlalu mahal |
| Herkullista! | Enak sekali! |

Huomaa **tolong** (pyydettäessä konkreettista apua, "auta minua") ja
**silakan** (kohteliaasti tarjottaessa tai kutsuttaessa, esim. "silakan
duduk" = ole hyvä ja istu) — nämä eivät ole vaihdettavissa keskenään.

## Kertausdialogi

```
A: Selamat siang! Bisa kamu bantu saya?
B: Tentu saja, silakan.
A: Di mana kamar kecil?
B: Di sana, sebelah kiri.
A: Terima kasih banyak.
B: Sama-sama.
```
(*tentu saja* = tietysti; *sebelah kiri* = vasemmalla puolella; *terima
kasih banyak* = kiitos paljon)

## Harjoitus 1: Täydennä puuttuva sana

Käytä lukujen 2 ja 6 sanastoa (tidak / bukan / sudah / belum / akan).

1. Saya _____ makan. (En ole vielä syönyt.)
2. Ini _____ buku saya, ini buku Budi. (Tämä ei ole minun kirjani.)
3. Saya _____ pergi ke pasar besok. (Menen huomenna torille.)

<details>
Vastaukset: 1. belum — 2. bukan — 3. akan
</details>

## Harjoitus 2: Käännä indonesiaksi

1. Hyvää huomenta, mitä kuuluu?
2. Nimeni on ... ja olen kotoisin Suomesta.
3. Kuinka paljon tämä maksaa?
4. Kolme kissaa ja yksi koira.

<details>
Vastaukset:
1. Selamat pagi, apa kabar?
2. Nama saya ... dan saya berasal dari Finlandia.
3. Berapa harga ini?
4. Tiga ekor kucing dan seekor anjing.
</details>

## Mistä jatkaa

Tämä oppikirja kattaa perusteet — luontevaa jatkoa ovat mm. laajempi
sanasto arkitilanteisiin (ruokailu, matkustaminen, ostokset), lisää
etuliitteiden (imbuhan) yksityiskohtia sekä kuuntelemisen harjoittelu
esim. indonesialaisten uutislähetysten tai podcastien kautta.
