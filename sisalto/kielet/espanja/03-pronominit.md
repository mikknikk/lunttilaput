## Persoonapronominit

| Suomeksi | Espanja |
| --- | --- |
| minä | yo |
| sinä (tuttavallinen) | tú |
| te/Te (kohtelias) | usted |
| hän (mies/nainen) | él / ella |
| me | nosotros / nosotras |
| te (monikko, tuttavallinen — lähinnä Espanjassa) | vosotros / vosotras |
| te (monikko, kohtelias — yleiskäyttöinen Latinalaisessa Amerikassa) | ustedes |

Näihin pronomineihin palataan tarkemmin luvussa 6, jossa jokainen
persoona saa oman verbin taivutuspäätteensä.
