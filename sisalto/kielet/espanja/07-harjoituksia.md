## Jokapäiväisiä hyödyllisiä fraaseja

| Suomeksi | Espanja |
| --- | --- |
| Voitko toistaa? | ¿Puedes repetir? |
| Puhun vähän espanjaa | Hablo un poco de español |
| Missä on vessa? | ¿Dónde está el baño? |
| Auttaisitko minua? | ¿Me puedes ayudar? |
| Kuinka paljon tämä maksaa? | ¿Cuánto cuesta esto? |
| Liian kallis | Demasiado caro |
| Herkullista! | ¡Qué rico! |
| Laskun, kiitos | La cuenta, por favor |
| Olen nälkäinen | Tengo hambre |
| Olen janoinen | Tengo sed |
| Nähdään pian | Hasta pronto |
| Näkemiin | Adiós |

Huomaa **tengo hambre** ja **tengo sed** — nälkä ja jano ilmaistaan
verbillä **tener** (olla jollakulla jotakin), ei kummallakaan luvun 6
olla-verbeistä ("olen nälkäinen" ei siis ole "estoy hambre"). Tämä on
hyvä esimerkki siitä, että espanjan idiomit eivät aina käänny suoraan
suomesta — sanonta on syytä opetella sellaisenaan.

## Kertausdialogi

```
A: ¡Hola! ¿Cómo estás?
B: Muy bien, gracias. ¿Y tú?
A: Bien también. ¿De dónde eres?
B: Soy de Finlandia. ¿Y tú?
A: Soy de México. ¿Tienes hambre? Hay un restaurante muy bueno cerca.
B: Sí, tengo mucha hambre. ¡Vamos!
```
(*muy bien* = oikein hyvin; *también* = myös; *hay* = on olemassa; *cerca*
= lähellä; *vamos* = mennään)

## Harjoitus 1: Taivuta verbi oikein

Käytä luvun 6 -ar/-er/-ir-taivutuskaavoja.

1. Yo _____ (hablar) español.
2. Nosotros _____ (comer) a las dos.
3. ¿Tú _____ (vivir) en Helsinki?
4. Ellos _____ (hablar) inglés y español.

<details>
Vastaukset: 1. hablo — 2. comemos — 3. vives — 4. hablan
</details>

## Harjoitus 2: Ser vai estar?

Valitse oikea verbi ja taivuta se oikeaan persoonaan.

1. Yo _____ (ser/estar) finlandés.
2. Nosotros _____ (ser/estar) cansados hoy.
3. El libro _____ (ser/estar) en la mesa.
4. Ella _____ (ser/estar) muy inteligente.

<details>
Vastaukset: 1. soy (pysyvä kansallisuus → ser) — 2. estamos (tilapäinen
olotila → estar) — 3. está (sijainti → estar aina) — 4. es (pysyvä
ominaisuus → ser)
</details>

## Harjoitus 3: Käännä espanjaksi

1. Hyvää huomenta, mitä kuuluu?
2. Nimeni on ... ja olen kotoisin Suomesta.
3. Kuinka paljon tämä maksaa?
4. Olemme väsyneitä.

<details>
Vastaukset:
1. Buenos días, ¿cómo estás?
2. Me llamo ... y soy de Finlandia.
3. ¿Cuánto cuesta esto?
4. Estamos cansados.
</details>

## Mistä jatkaa

Tämä oppikirja kattaa perusteet — luontevaa jatkoa ovat mm. mennyt aika
(pretérito, imperfecto), epäsäännölliset verbit (esim. tener, ir, hacer)
sekä laajempi sanasto arkitilanteisiin (ruokailu, matkustaminen,
ostokset).
