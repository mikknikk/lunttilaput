## Numerot 1–10

| Kanji | Japani (hiragana) | Kunrei-shiki (ISO 3602) |
| --- | --- | --- |
| 一 | いち | iti |
| 二 | に | ni |
| 三 | さん | san |
| 四 | よん / し | yon / si |
| 五 | ご | go |
| 六 | ろく | roku |
| 七 | なな / しち | nana / siti |
| 八 | はち | hati |
| 九 | きゅう / く | kyû / ku |
| 十 | じゅう | zyû |

Osalla numeroista on kaksi ääntämystä — esim. numeroa 4 ei yleensä lausuta
"si", koska se on homofoni kuolemaa tarkoittavalle sanalle.
